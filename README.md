# OrangeHRM Manual Testing Project

## 📌 Project Overview
This project demonstrates end-to-end manual testing of the OrangeHRM web application.  
The objective is to ensure the quality, functionality, and usability of the HR management system by executing structured test cases and reporting defects.

---

## 🎯 Objectives
- Validate core functionalities of OrangeHRM application
- Identify functional and UI defects
- Ensure system meets business requirements
- Create proper testing documentation

---

## 🧪 Modules Covered
- Login / Logout
- Admin Module
- PIM (Personal Information Management)
- Leave Management
- Time Tracking
- Dashboard

---

## 🔍 Types of Testing Performed
- Functional Testing
- UI Testing
- Regression Testing
- Smoke Testing
- System Testing
